Every dashboard ends with a follow-up question.
Leave the page to ask an analyst and you lose time.
Leave it to ask an agent and you lose context.
Dashboards don't need replacing. They need a way to answer back.

The question has to go somewhere.

The analyst
Cost: time

Works. Costs two people an afternoon — the stakeholder waits, the analyst is pulled off a report they already finished.

The standalone agent
Cost: context

Fast — and the first thing it asks is which report, which filters, what you mean. The human re-supplies the context, badly.

What it takes

Three things you have to build for the handover to be real.
1

Grounding

The agent inherits the report's query and definitions.
It does not infer its own.
2

Trust

Show the work — or say "I can't answer that from this report."
That refusal is a feature, not a failure.
3

Permissions

Some filters aren't a choice — they're the rows the viewer is allowed to see.
The agent answers for the page the viewer has, not the table the warehouse has.
